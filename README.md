# M5APRS

M5Stack Basic GPS APRS tracker/receiver (1200bps AFSK)

[English](README.en.md) | 日本語

M5Stack Basic V2.6 で、GPS の位置を APRS パケットにして 1200bps AFSK で無線機へ送り、無線機で受信した APRS をデコードして画面に表示するアマチュア無線用のソフトです。個人の趣味のプロジェクトで、M5Stack 社とは関係ありません。

## 主な機能
- GPS (NMEA) の位置から、APRS の位置レポート (非圧縮形式) を作って送信 (A長押しで1パケット、または自動送信)
- ビーコンの自動送信: オフ / Ackのみ / 1〜60分ごと / フレックス (設定メニューで選択。電源を切っても保持)。他局の送信中は止むまで待つ
- フレックス: 速度と曲がり方で送信の間隔を変える。八重洲・ケンウッドの無線機のスマートビーコニングと同じ方式・同じ項目で、値は config.txt に書く
- 送信時に PTT を自動で ON/OFF (GPIO5 → トランジスタ)。PTT の最大時間は 10 秒
- 1200bps AFSK (Bell 202) の受信・デコード。非圧縮形式、圧縮形式、Mic-E の位置や、メッセージなどを受信一覧に表示
- メッセージ: 自分宛てのメッセージと一斉通知の受信、Ackの自動返送、メッセージの送信 (Ackが来るまで送り直し)。宛先は受信した局から、本文は定型文から選ぶ。CardKB2 をつなげば文字も入力できる
- 受信音: パケット・自局の折り返し・Ack・メッセージで音を分けて鳴らす (音量はモニター音とは別に設定)
- 記録の消去: 受信一覧・WX局・メッセージ・レーダーの局を、設定メニューから一覧ごと (またはすべて) 消せる (確認つき)
- WX(気象)画面: 気象データを含むパケットを受信した局 (最大8局) の気温・湿度・気圧・風・雨量を一覧と詳細で表示
- 受信状態の画面: 信号あり / データ受信中 / 受信OK / CRC不良、入力レベル、MARK/SPACE のトーン強度と比 (直近に受けた局の比も)、受信OK・CRC不良・雑音の件数
- 位置の取得元を手動で選択: GPS / 最後の位置 / 固定位置 (config.txt に最大8件)
- 送信音のモニター (内蔵スピーカー、5段階)
- 調整トーン: 設定メニューから、PTT付きで連続トーン (1200Hz / 2200Hz / 交互) を出して、減衰回路や送信レベルを調整できる (ダミーロード前提)
- シリアルモニタ (115200bps) への診断出力: PTTのタイミング、送受信パケット、受信の状態、定期の状態
- microSD に受信ログ (CSV) と動作ログを保存
- コールサインなど局ごとの設定は microSD の `config.txt` に書く (ビルドのときに書き換えるファイルはない)
- シンボル (21種類) と SSID (0〜15) を別々に設定。受信一覧・詳細・自局画面にシンボルのアイコンを表示
- レーダー画面: 自局を中心に、受信した局をシンボルのアイコンとコールサインで表示 (距離 1〜100km・自動、時間 10分〜24時間を切り替え)
- 画面の表示を日本語 / English で切り替え (設定メニューの「言語 / Language」)
- バージョン情報: 設定メニューの最後の項目で、バージョン (`version.h`)・ビルド日時・対応基板の版を表示

## 構成 (ハードウェア)
| 項目 | 内容 |
|---|---|
| 本体 | M5Stack Basic V2.6 |
| GPS | M5Stack 用 GPS モジュール (UART2: RX=GPIO16, TX=GPIO17, 115200bps) |
| 送信 | DAC GPIO26 → 減衰回路 → 無線機のマイク端子 |
| モニター | DAC GPIO25 (内蔵スピーカー) |
| PTT | GPIO5 → LED (PTT 表示を兼ねる) + 抵抗 → NPN トランジスタ (IF v1 は 2SC2712)。マイク線を抵抗を通して GND に落とす |
| 受信 | 無線機のイヤホン端子 → ADC GPIO36 (直流バイアス付き) |
| 記録 | 内蔵 microSD (CS=GPIO4) |

減衰回路、受信の入力回路、PTT 回路は外付けの基板です。IF v1 基板の設計データ (回路図、基板、部品表、ガーバー) は `hardware/` にあります。無線機はアナログ FM で使います。動作を確認した無線機は「現状」と `hardware/radio_compat.md` を参照してください。

> 注意: DAC の出力は約 2.6Vpp あるため、無線機のマイク入力へは必ず減衰させてください。PTT 線に GPIO を直結しないでください。

## 使い方
1. Arduino IDE に **ESP32 ボードパッケージ 2.x** (動作確認の想定は 2.1.4。3.x は未対応) と、ライブラリ **M5Unified** を入れる
2. このリポジトリを `M5APRS` という名前のフォルダに置く (Arduino IDE はスケッチ名とフォルダ名が同じである必要がある)
3. `M5APRS.ino` を開き、ボード「M5Stack-Core-ESP32」などを選んで書き込む (書き換えるファイルはありません)
4. microSD カード (FAT32 でフォーマットしたもの。32GB 以下の SDHC など) を入れて起動すると、`/aprs/config.txt` (見本) ができるので、パソコンで開いて書き換え、カードを戻して再起動する
   ```
   callsign = N0CALL
   comment  = M5Stack APRS
   fixed1   = Home, 35.68123, 139.76712, 12
   ```
   最低限 `callsign` を自分のコールサインに書き換える (SSID は本体の設定メニューで選ぶ)。`NOCALL` のままでは送信しません

### 設定ファイル config.txt
- 1行に1つ「キー = 値」で書きます。行の先頭が `#` の行はコメントです (値の途中の `#` は文字として扱います)
- 書けるのは、コールサイン、コメント、固定位置 (8件)、デジパスの候補 (3つ)、メッセージの定型文と宛先の候補 (各8件)、送信レベル・PTT のタイミングなど無線機に合わせる値です。項目の一覧は `docs/APRS_M5Stack_spec.md` の 3.1 と、見本のファイルのコメントにあります
- 読むのは起動時だけです。書き間違いのある行は無視され、起動時の画面と、設定メニューの「バージョン情報」に行番号が出ます
- 読めた内容は本体にも控えておくので、microSD を抜いても前回の設定で動きます (SD に config.txt が無いときは、控えから書き戻します)
- 書き換えたあと、そのカードをそのまま他の人に渡すとコールサインも渡るので注意してください

## 操作
| ボタン | 短押し | 長押し |
|---|---|---|
| A | 前 (前の画面・項目) | **ビーコン送信** |
| B | 決定 (開く・変更・開始) | 戻る (1つ上へ) |
| C | 次 (次の画面・項目) | 設定メニュー (開く・閉じる) |

短押しはその画面の中の操作、長押しはどの画面でも同じ働きです。

受信一覧・WX局・メッセージ・レーダーの局はmicroSDに保存され、電源を入れ直しても残ります (送り直しの途中だったメッセージは「応答なし」になります)。

画面の下には、ボタンごとの働きを枠で囲んで出します (上段=短押し、下段=長押し)。画面上端の右側には、電池・SDカード・音量・受信音・GPS/位置・自動送信・送受信・未読メッセージの状態をアイコンで出します。

画面は 自局 / 受信一覧 / レーダー / メッセージ / WX / 受信状態 / 送信・設定 の7つです。設定メニューでは、位置の曖昧化、デジパス、シンボル、SSID、進行方向・速度、高度、モニター音量、受信音の音量、画面の明るさ、位置の取得元、表示の言語などを変えられ、記録の消去もできます。詳しくは `docs/` を参照してください。

## テスト
計算部分 (AFSK、AX.25/APRS、NMEA、設定、ログ、画面の組み立てなど) は、ESP32 なしでパソコン上でテストできます (g++ が必要)。
```
./tests/run_tests.sh          # 初期値の設定でテスト
./tests/run_tests.sh fixed    # 固定位置を設定した状態でテスト
```
実機でのタイミング、DAC/ADC の特性、外付け回路は、実機で確認する必要があります。

## 現状
ICOM ID-31 / ID-52、スタンダード C601 / C701 と IF v1 基板の組み合わせで動作を確認しています。config.txt の送信レベルなどの初期値は、この組み合わせで確かめた値です。
