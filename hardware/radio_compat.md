# 無線機との相性

M5APRS のインターフェース回路を、いろいろな無線機につないで試した結果の記録です。
「試作」はユニバーサル基板で組んだもの、「IF v1」は JLCPCB で製作した基板 (hardware/ の KiCad データ) です。
機種ごとに分かったことを追記していきます。

## 試作での ID-52 の回り込み (IF v1 では解消)

### 症状
- 無線機のスケルチが開いて大きな信号を受けると、PTTが入ってしまう (勝手に送信状態になる)

### 分かったこと
| 試したこと | 結果 | 分かること |
|---|---|---|
| A: PTTの線 (R3) を切る | 変わらず PTTが入る | PTTの回路 (2SC2712) が原因ではない |
| B: SPのスリーブ (GND) の線を外す | 悪化する | SPの音声の電流は、SPのスリーブ線を通って戻っている |
| C: SPとMICのスリーブ間の抵抗 | ほぼ 0Ω | 無線機の中で SP と MIC の GND は共通 (BTL ではない) |
| D: C3 と MIC の Tip の間に 22kΩ を直列に入れる | 変わらず | 送信の音声経路 (C3・RV2) からの漏れでもない |
| 受信音量を下げる | 音量 10 で回り込みが出始め、9 なら出ない | 復調に必要な最低の音量は 9 で、余裕は1目盛りしかなかった |

### 結論
- 同じ回路の IF v1 (GNDベタのある2層基板) では、ID-52 を音量最大にしても回り込まない
- 試作の回り込みは、回路ではなく、ユニバーサル基板の GND の配線 (細い線・長い引き回しで、SP の受信音の電流と MIC 側が GND を共有していた) によるものと考えられる
- IF v2 での分離 (音声のトランス、PTTのフォトカプラ) は、今のところ不要。回り込む機種が見つかったら改めて検討する

## 記録の雛形

新しい機種を試したら、次の項目を記録して上の表に追加する。

| 項目 | 記入例 |
|---|---|
| 基板 | IF v1 / 試作 |
| 機種名・プラグの形 | ID-52、3.5mm(SP) + 2.5mm(MIC) |
| 回り込みが出るか | 出る / 出ない (音量最大でも) |
| 回り込みが出始める無線機の音量 (目盛り) | 音量 15 で発生、12 なら出ない |
| 復調に必要な最低の音量 (受信状態画面の入力レベル) | 音量 8 で入力 30% |
| 調整トーン・パケットの送受信 | 問題なし |
| SP と MIC のスリーブ間の抵抗 | ほぼ 0Ω |
| A: PTTの線を切ったとき | 変化なし |
| B: SPのGNDを外したとき | 悪化 |
| D: 22kΩ を入れたとき | 変化なし |
